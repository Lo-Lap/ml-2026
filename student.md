# Курс "Машинное обучение"

- Результат: практическое знание необходимое для построение ПО с использованием ML. По итогам требуется предоставить реально работающее web-приложение, на серверной части которого работает ML-модель.

- Группы делятся на команды не более 2-х человек. Желающие могут выполнять работу самостоятельно, т.е. группа может состоять из одного человека.

- Команда выбирает проект, в котором обязательно должна присутствовать ML-составляющая. В качестве проекта может быть выбран ВКР-проект, существующий рабочий проект (если студент где-то работает) или это может быть совершенно новый придуманный проект.

## Командная работа

- После утверждения проекта каждая команда еженедельно на занятиях предоставляет краткий отчет по проделанной работе. Отчеты выкладываются в [git-репозитории](https://github.com/job-modelware-ru/ml-2026).

- Структура git-репозитория. Например, для команды **01** структура директорий следующая:
- 01\
    - 07.09-13.09.md - отчет о проделанной работе за неделю
    - 14.09-20.09.md - отчет о проделанной работе за неделю

- Сами проекты хранятся в частных репозиториях.

По итогам команды делают презентацию проекта.

## Правила выставления оценок

За курс можно получить максимум 100 баллов, которые соответствуют оценкам:
- 91-100 - отлично
- 71-90 - хорошо
- 51-70 - удовлетворительно
- менее 51 - неудовлетворительно

Баллы начисляются:
- наличие, своевременность и полнота отчетов: от 0 до 10
- представление результатов работы: от 0 до 90
